# Fonts

The deck uses the same three typefaces as the rest of the series, served from this folder so that the page makes no
external requests. Each file is the Latin subset of the variable font as served by Google Fonts (fetched 2026-10-19):

| File | Typeface | Licence |
|---|---|---|
| `BricolageGrotesque-normal-latin.woff2` | Bricolage Grotesque | SIL Open Font License 1.1 |
| `InstrumentSans-normal-latin.woff2`, `InstrumentSans-italic-latin.woff2` | Instrument Sans | SIL Open Font License 1.1 |
| `GeistMono-normal-latin.woff2`, `GeistMono-italic-latin.woff2` | Geist Mono | SIL Open Font License 1.1 |

The SIL Open Font License 1.1 is at https://openfontlicense.org. The fonts are not modified; the font software is
redistributed under its own licence, not the deck's CC BY 4.0 or the code's MIT licence.
